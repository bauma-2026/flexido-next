# Flexido favicon / app icon set

Color:
- background: #0082CA
- symbol: #FFFFFF

Recommended Next.js App Router placement:
- `src/app/favicon.ico`
- `src/app/icon.png`
- `src/app/apple-icon.png`

Recommended public placement:
- copy remaining files to `public/icons/`
- copy `og-fallback.png` to `public/og/flexido-og.png` if you want to use it for Open Graph.

Optional `<head>` / metadata usage:
- manifest: `/icons/site.webmanifest`
- browserconfig: `/icons/browserconfig.xml`
- safari pinned tab: `/icons/safari-pinned-tab.svg`
- theme color: `#0082CA`
